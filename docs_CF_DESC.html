Goetied - A Magic & Necromancy Mod

Goetied is the display name for this NeoForge port of Goety. The in-game mod ID remains `goety` so existing worlds, configs, and datapacks keep working.

Goetied brings a rich magic system and dark fantasy elements to Minecraft, offering players new ways to engage with combat, exploration, and progression through spellcasting and necromancy.

Core Features

Spellcasting System

Master multiple schools of magic including necromancy, geomancy, storm magic, nether magic, wind magic, wild magic, and void magic. Each school offers unique spells with different mechanics and strategic applications. Research new spells through scrolls and manage your soul energy to power your magical abilities.

Servant System

Summon and command a variety of loyal servants to aid you in battle. Raise undead minions, recruit illager allies, construct powerful golems, or command ender creatures. Each servant type has unique abilities and can be equipped with armor and weapons.

Lich Transformation

Undergo a powerful ritual to transform into a Lich, gaining new abilities and a different playstyle focused on undeath. Liches have unique mechanics, powers, and limitations that change how you interact with the world.

Mystical Structures

Discover procedurally generated structures throughout your world including graveyards, crypts, dark manors, sorcerous keeps, and spider dens. These structures contain valuable loot, unique mobs, and opportunities for adventure.

Brewing & Rituals

Create custom potions and brews with unique effects using the advanced brewing system. Perform powerful rituals to craft items, transform yourself, or achieve other magical effects.

Equipment & Progression

Wield powerful magic staves, equip specialized armor sets with unique abilities, and wear magical curios for additional powers. Collect and manage soul energy through totems to fuel your magical endeavors.

Technical Details

How This Project Differs from the Original

This NeoForge port brings the original Goety mod to Minecraft 1.21.1, with the following key differences:

  • Mod Loader: Ported from Minecraft Forge to NeoForge (the successor to Forge)
  • Minecraft Version: Updated from earlier versions to Minecraft 1.21.1
  • API Updates: All systems have been updated to use NeoForge's modern APIs
  • Code Modernization: Updated to Java 21
  • Bug Fixes: Resolved compatibility issues and bugs specific to the NeoForge port
  • Maintenance: Active maintenance and updates for NeoForge 1.21.1+

What's the Same: Gameplay, registry IDs under the `goety` namespace, items, mobs, structures, and configs remain compatible with prior Goety NeoForge builds from this project.

We extend our gratitude to Polarice3 for creating the original Goety mod and all the contributors, artists, builders, and translators who have helped make this mod what it is today.

Installation

  • Install NeoForge 21.1.34 or later for Minecraft 1.21.1
  • Install Curios API 9.5.1 or later (required)
  • Download and install Goetied (jar still uses the `goety` mod ID)
  • Launch and enjoy!

Configuration

Configuration files are located in your `config/goety/` directory.
