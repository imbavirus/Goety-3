# Version 3.0.14

## Bug Fixes

### Armor & Damage

- **Fixed Leather Armor Invulnerability:** Wearing vanilla leather armor no longer grants Black Iron / Dark armor damage reduction. Custom armor materials are registered properly again so only the intended sets get those bonuses.
- **Restored Magical Armor Damage Reduction:** Black Iron and Dark armor set reduction math for magic, fire, and explosion damage works as originally intended.

### Curios, Totems & Config

- **Fixed Curios Integration:** Goetied curios items and slots work correctly again on NeoForge 1.21.1.
- **Fixed Totem of Souls Crafting / JEI:** Totems are craftable again and show up properly in JEI.
- **Fixed Config Generation:** Mod config files generate correctly on first launch.

### Focuses & Summons

- **Restored Call, Troop, and Command Focuses:** These focuses again resolve and teleport / command summoned servants instead of failing as stubs.
- **Spawner Infusion:** Spawner infusion behavior is ported and working for 1.21.1.

### Registry, Tags & Models

- **Paintings & Banners:** All Goetied painting variants and banner patterns register correctly.
- **Biome Tags:** Added the missing `#c:is_peak` biome tag used by worldgen / structure logic.
- **Black Crystal, Chests & Infernal Tome:** Fixed missing/broken block entity renderers and the Infernal Tome active item model predicate.

### Networking & Rendering

- **World Sound Packets:** Server world sound networking updated for the 1.21.1 payload system.
- **Particle Rendering:** Fixed particle rendering issues introduced during the port.
- **Wands & Network:** Wand interaction and related network handling fixes for 1.21.1.

### Config Defaults

- **Tool Tier Durability:** Tier and related config helpers no longer treat invalid `0` defaults as usable durability values.
