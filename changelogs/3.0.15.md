# Version 3.0.15

## Bug Fixes

### Dedicated Server

- **Fixed dedicated server crash loading `ClientSideInit`:** client proxy and sided init no longer construct `ClientProxy` / `ClientSideInit` from common static initializers.
  - Client setup is gated with `FMLEnvironment.dist == Dist.CLIENT` and runs only through `ClientBootstrap`.
  - Restores particle providers and item client extensions on clients without breaking dedicated servers.
