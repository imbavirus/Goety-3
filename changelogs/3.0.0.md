# Version 3.0.0

## Initial NeoForge Port & Working State

This version marks the successful port of Goetied from Minecraft Forge to NeoForge, bringing the mod to a fully working state on Minecraft 1.21.1.

### Changes
- **Port to NeoForge**: Complete migration from Minecraft Forge to NeoForge
- **Minecraft Version**: Updated to support Minecraft 1.21.1
- **Stability**: All major systems have been ported and tested to ensure a stable gameplay experience

### Technical Notes
- All mod systems have been updated to use NeoForge APIs
- Registry system migrated to NeoForge's deferred registration system
- Attachment system implemented to replace the old Capability system
- Structure generation and worldgen features updated for 1.21.1
- Model layer registration system updated for proper client-side rendering
- All known crashes and rendering issues have been resolved
