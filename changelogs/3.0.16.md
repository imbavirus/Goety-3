# Version 3.0.16 (withdrawn)

The world-breaking mod-id rename (`goety` → `goetied`) release was **withdrawn** from CurseForge and Modrinth.

- Display branding as **Goetied** is kept (title/name).
- In-game **mod ID stays `goety`** so existing worlds, configs (`config/goety/`), and datapacks keep working.
- JARs continue as `goety-*-neoforge-1.21.1.jar`.

Use **3.0.15** (or later compatible builds) until a new release is published.
