# Version 3.0.16

## Rebrand

- **Renamed the mod from Goety to Goetied** across the full project:
  - Mod ID: `goety` → `goetied`
  - Display name: **Goetied**
  - Java package: `za.co.infernos.goetied`
  - Asset/data namespaces, mixins, configs, and creative tabs use `goetied`
  - JAR artifact name: `goetied-*-neoforge-1.21.1.jar`
  - GitHub repository: [imbavirus/Goetied-3](https://github.com/imbavirus/Goetied-3)

## Compatibility note

- **World / config break:** existing worlds and configs that reference the old `goety` namespace will not load this build as a drop-in replacement. Use a new world or migrate data intentionally.
- Dedicated-server client-init fix from 3.0.15 is retained (`ClientBootstrap` dist gate).

## Credits

This remains a NeoForge 1.21.1 port of the original **Goety** mod by **Polarice3**, maintained by Infernos as **Goetied**.
