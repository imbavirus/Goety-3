# Version 3.0.19

## Fixes

- Rippers no longer crash the server when poison (or a second reinforcement) tries to apply the same `caller_charge` attribute twice.

## Balance

- Hostile Necromancer magic bolts: 2 damage (was 4, and could bake as 20 if config was unread at registry), fired every 2s instead of 1s.
- Necromancer combat summons cap 3 (was 7), recast every 10s (was 5s). Idle summons 1–2 (was 2–5).
- Extra natural Necromancer spawn: max 1 nearby, much rarer. Vanilla forest/desert weight 1 is unchanged.
